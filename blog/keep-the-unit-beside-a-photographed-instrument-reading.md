---
title: "Keep the unit beside a photographed instrument reading"
date: 2026-11-01
description: "Keep the unit visible and tied to the same photographed instrument reading."
---

Keep the unit in the photograph of an instrument reading. A reviewer looking only at a cropped number may not know which scale it uses.

Take an overview that shows the display and its nearby labels without changing the instrument's settings. If the display has a unit indicator, retain it in the reading copy. A separate label elsewhere on the housing belongs in an additional reference view when it cannot fit clearly in the same frame.

Name the views so the number and the unit can be matched to the same observation. If the unit cannot be established from the photograph or an accompanying record, mark it as unknown. Do not infer it from the size of the number. A photograph also does not establish that an instrument was calibrated or used correctly.

Open the exported reading copy at its intended viewing size before sharing it. Check that the unit indicator is still legible. Keep the overview beside it so a later crop can be checked against the source. I work on [Morphio](https://morphio.online/) and write about preparing images for handoff; the observation record supplies context that a cropped number may lose.
