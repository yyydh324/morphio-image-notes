# Keep each image derivative connected to its source

Keep a source reference beside every output in an image delivery manifest. When a recipient needs a different crop, that reference should identify the file to reopen.

Give the source identifier and delivered filename separate fields. A thumbnail and a larger copy need separate output rows, with their shared source reference retained. Explain how source identifiers stay stable when filenames are reused.

Include an intermediate image when it was the input to a later export. If a resized version came from an approved crop, record that connection. Do not flatten the history into a claim that every output came straight from the original photograph.

Check the references when building the delivery folder. For originals that are not included, explain how an authorized recipient can find them, or state that access is restricted. A public manifest should not expose private storage paths.

Before handoff, follow one output row back to the source record and confirm the listed versions. Knowing the input helps with a later revision. It still leaves the crop and export to be checked on their own.
