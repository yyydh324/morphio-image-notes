---
title: "Keep a coordinate reference beside an image annotation"
date: 2026-11-02
description: "Keep image dimensions and a coordinate reference with annotations that need to survive a crop or resize."
---

Name the image dimensions when handing off pixel coordinates for an annotation. Coordinates from a source file can be mistaken for coordinates in a resized copy.

Identify the exact image version in the note. Record the width and height used when selecting the position, along with the coordinate convention your workflow uses. In a hypothetical example, say whether the point is measured from the top-left corner of that file.

When the image changes size or orientation, review the annotation against the new version. Check the result before carrying the old coordinates into the delivery record. If you cannot recover the original coordinate reference, mark the location as uncertain and ask for a new selection.

Open the annotated copy beside its unmarked source before delivery. Check that the mark identifies the intended feature and that its filename agrees with the note. Keep the coordinate record as text so another editor can locate the same position without estimating it from the visible mark.
