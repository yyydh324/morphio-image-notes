---
title: "Record the expected output count in an image delivery manifest"
date: 2026-10-30
---

Give the recipient an expected output count tied to the delivered filenames. Count omitted sources separately so the transfer check describes the actual folder.

Count delivered files separately from source images and deliberately omitted items. A source can produce more than one output, so the source count alone may not describe the folder being sent. List each delivered filename on a separate row.

Record deliberate gaps with an explicit status and explanation. Keep an omitted source out of the delivered-file count. If the expected count changes during preparation, update the manifest before sharing the folder.

Check the listed filenames against the actual delivery folder. Open any file whose name is ambiguous and resolve duplicate entries. Keep the checked manifest with that delivery version so the count refers to a specific set.
