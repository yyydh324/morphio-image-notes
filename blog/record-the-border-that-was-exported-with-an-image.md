# Record the border that was exported with an image

A white strip around a photo in a preview may belong to the page. To find out whether it is in the delivered file, open the export in an image viewer with a contrasting background and inspect the edges.

If the export adds a border, record it beside that file in the manifest. Include its color and the width of each side when you know them. If the layout leaves extra room for a caption, name the edge with the wider border.

Record the full pixel dimensions of the file. If the space available to the picture matters for placement, list the picture area separately. Check both against the actual export before giving either number to the person placing the image.

I work on [Morphio](https://morphio.online/). When a HEIC source becomes a padded JPEG for delivery, put the border information on the JPEG’s line and keep the HEIC source with the working files.
