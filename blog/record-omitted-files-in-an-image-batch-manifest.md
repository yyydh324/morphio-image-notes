# Record omitted files in an image batch manifest

Record omitted source identifiers beside the delivered files in a batch manifest. Keep their status clear so an empty output field does not look like an upload failure.

Use the same source identifiers as the requested set. Describe each omission briefly without placing private material into the delivery folder merely to prove it existed. Keep the original record in the appropriate private archive.

Use separate statuses for delivered outputs and omitted sources. A hypothetical entry can say source-07: omitted, duplicate view; the delivered-file field can remain empty. Avoid giving a nonexistent output a filename that looks ready to download.

Check the manifest against the actual delivery folder before sharing it. Every delivered filename should resolve to the intended file, and each deliberate gap should have a recorded explanation.
